# שיבוץ מקומות — בית מדרש תפארת יהודה

מערכת אינטראקטיבית לניהול ושיבוץ מקומות ישיבה לימים נוראים.
**קובץ HTML אחד בלבד** — ללא התקנה, ללא שרת, ללא ספריות חיצוניות.

## הפעלה

פותחים את `index.html` בדפדפן (Chrome / Edge מומלץ). זהו.

## מבנה המקומות

| אזור | תיאור | מספור |
|---|---|---|
| בית המדרש | לרוחב. ארון קודש בחזית, בימה במרכז | שורה א׳, ב׳, ג׳… |
| שולחנות צד ימין | 4 מקומות בכל שולחן | 1 · 2 · 3 · 4 |
| סטנדרים במרכז | שני טורים, 2 מקומות בכל סטנדר | 1 · 2 |
| שולחנות צד שמאל | 4 מקומות בכל שולחן | 1 · 2 · 3 · 4 |
| עזרת נשים | לאורך, בצד שמאל, מופרדת במחיצה. 11 שולחנות של 3 מקומות | שולחן א׳, ב׳, ג׳… |

## שימוש

- **לחיצה על מקום** פותחת חלון עריכה: תואר לפני (ברירת מחדל `ה"ה`), שם פרטי, שם משפחה, תואר אחרי (ברירת מחדל `הי"ו`), טלפון, הערות.
- כפתורים: **שמירה** · **שולם** · **פינוי מקום** · **ביטול**.
- צבעי המפה: 🟢 שולם · 🔴 תפוס וטרם שולם · ⬜ פנוי.
- על המפה מוצגים שם פרטי ושם משפחה בלבד; התארים מופיעים ביצוא.
- חיפוש לפי שם או טלפון מסמן את המקום וגולל אליו.

## יצוא

**מפה (PDF / הדפסה)** — לרוחב, עם התאמה אוטומטית לעמוד יחיד:

- היקף: בית המדרש בלבד · עזרת נשים בלבד · מפה מלאה.
- מועד: ראש השנה (גווני חום · שמנת · זהב) או יום הכיפורים (זהב מלכותי · לבן).
- כותרת: `שיבוץ מקומות [המועד] בית מדרש תפארת יהודה`.
- אפשרות להצגת תארים על המפה ולצביעה לפי סטטוס תשלום.
- בחלון ההדפסה של הדפדפן יש לבחור **שמירה כ-PDF** ולסמן **גרפיקת רקע** כדי לשמור על הצבעים.

**טבלה (Excel)** — שלוש עמודות: `שורה / שולחן` · `מספר מקום` · `שם מלא כולל תארים`
(לדוגמה: `שורה א׳ — צד ימין | 1 | ה"ה אברהם כהן הי"ו`), עם כותרת לפי המועד וייצוא נפרד לכל אזור.

## נתונים

הנתונים נשמרים אוטומטית ב-`localStorage` של הדפדפן במחשב זה.
כפתור **גיבוי** מאפשר הורדת קובץ JSON ושחזור ממנו — מומלץ לגבות לאחר עדכונים.

## שינוי מבנה האולם

בראש בלוק ה-`<script>` שבקובץ נמצא אובייקט `CONFIG`:

```js
var CONFIG = {
  hallName: 'בית מדרש תפארת יהודה',
  hall: {
    rows: 4,             // מספר שורות באולם
    rightSeats: 4,       // מקומות בכל שולחן בצד ימין
    leftSeats: 4,        // מקומות בכל שולחן בצד שמאל
    shtenderColumns: 2,  // טורי סטנדרים במרכז
    shtenderSeats: 2,    // מקומות בכל סטנדר
    bimahAfterRow: 2     // מיקום הבימה
  },
  women: { tables: 11, seats: 3 }
};
```

המספרים הנוכחיים הם זמניים — יעודכנו לפי הצורה המדויקת של הבית מדרש.
